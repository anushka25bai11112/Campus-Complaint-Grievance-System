CAMPUS GRIEVANCE SYSTEM
========================

Language:
Java

Project Type:
Console Based Application

Features:
1. Student complaint submission
2. Complaint ID generation
3. Search complaint
4. View all complaints
5. Admin complaint management
6. Update complaint status
7. Pending status
8. In Progress status
9. Resolved status
10. Rejected status

How to Run:

Step 1:
Open terminal in the project folder.

Step 2:
Compile:

javac -d out src/*.java

Step 3:
Run:

java -cp out CampusGrievanceSystem
